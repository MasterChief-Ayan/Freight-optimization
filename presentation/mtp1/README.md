## Outcome and lesson (13-Nov-2026)
Results came across well, but the panel was doubtful about **how** they were obtained: the deck had no
method block (formulation, data, experimental design) and no Future Work slide. The next deck
(MTP-2, external evaluator) must show the method before the results, state under every result how it
was obtained, define every number before use, and include Limitations + Future Work. See
`docs/PROJECT_STORY.md` §6K.
